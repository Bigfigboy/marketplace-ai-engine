# Запуск в облаке без VS Code и локального терминала

Цель — показать AI Engine команде: открыть ссылку в браузере, ввести ключ и проверить трёх агентов.
Всё делается в веб-интерфейсах GitHub и Render. **Сам деплой выполняет человек из команды** — в рамках
разработки ничего не публиковалось.

## Рекомендуемый вариант: Render (Docker, бесплатный план)

Почему Render: собирает наш `Dockerfile` прямо из GitHub, настройки задаются в браузере, в репозитории
уже есть `render.yaml`, есть бесплатный план для веб-сервисов, HTTPS включён автоматически.

Ограничения бесплатного плана (проверьте актуальные условия на сайте Render при регистрации):
- после ~15 минут без запросов сервис «засыпает», первый запрос будит его около минуты;
- диск не сохраняется: при перезапуске или передеплое база SQLite, ключи и загруженные файлы
  **сбрасываются** (для демо это нормально: `DEMO_API_KEY` создаётся заново при старте);
- 512 MB памяти — поэтому в `render.yaml` стоит `EXTRACTION_MEMORY_MB=256`.

> Сервис получает публичный адрес `https://<имя>.onrender.com`. Без ключа доступа API и данные
> недоступны (кроме `/health`, `/docs` и статической страницы `/demo`), но сам адрес публичный.
> Расходы на OpenAI ограничены `DAILY_SPEND_LIMIT`, `COMPANY_DAILY_SPEND_LIMIT` и лимитом
> 10 запросов на пользователя в день. Дополнительно задайте лимит расходов в кабинете OpenAI.

### Шаг 0. Подготовьте значения (в браузере)

1. **OpenAI API-ключ**: platform.openai.com → API keys → Create new secret key. Рекомендуется отдельный
   проект с месячным лимитом расходов (Settings → Limits).
2. **Тарифы модели**: на странице цен OpenAI найдите цены для `gpt-4.1-mini` за 1M входных и 1M выходных
   токенов (USD). Они понадобятся для `PRICE_INPUT_PER_1M_TOKENS` / `PRICE_OUTPUT_PER_1M_TOKENS`.
3. **Ключ демо-доступа**: строка, начинающаяся с `aie_`, и затем не менее 32 случайных букв/цифр
   (например, из менеджера паролей: сгенерируйте пароль из 40 символов без спецсимволов и допишите
   спереди `aie_`). Это пароль для команды — передавайте его только в закрытом чате.

### Шаг 1. Создайте сервис

1. Зайдите на https://render.com → **Sign in with GitHub**. Разрешите доступ к репозиторию
   `bigfigboy/marketplace-ai-engine`.
2. **New → Blueprint** → выберите репозиторий → в поле ветки выберите
   **`claude/keen-shannon-qawv3n`** (или ту ветку, куда команда смержит работу).
3. Render прочитает `render.yaml` и покажет сервис `ai-engine-demo`. Он попросит значения для полей
   без значения по умолчанию:
   - `OPENAI_API_KEY` — ключ из шага 0.1;
   - `PRICE_INPUT_PER_1M_TOKENS`, `PRICE_OUTPUT_PER_1M_TOKENS` — числа из шага 0.2 (точка как разделитель);
   - `DEMO_API_KEY` — ключ из шага 0.3.
4. Нажмите **Apply / Deploy**. Сборка Docker-образа занимает несколько минут; следите во вкладке **Logs**.
   В логе должно появиться `"event": "startup"` и `"llm_mode": "openai"`.

Если Blueprint недоступен: **New → Web Service** → репозиторий → Runtime **Docker**,
Dockerfile Path `./ai-engine/Dockerfile`, Docker Build Context `./ai-engine`, Instance Type **Free**, Health Check Path
`/health`, затем во вкладке **Environment** добавьте переменные из `render.yaml` вручную.

### Шаг 2. Проверьте

1. Откройте `https://<имя>.onrender.com/health` — должно быть `"status": "ok"`, `"llm_mode": "openai"`,
   `"llm_configured": true`.
2. Откройте `https://<имя>.onrender.com/demo/` → вставьте `DEMO_API_KEY` → **OK**.
3. Агент **Marketing**: «Создай контент-план для кофейни в Алматы». В ответе должны быть чипы
   `OpenAI · gpt-4.1-mini`, ненулевые токены и стоимость. Если видите `MOCK` — `LLM_MODE` не `openai`.
4. Агент **Support**: в блоке «Файлы» загрузите `kb_coffee_ru.txt` (скачайте из GitHub:
   `ai-engine/examples/files/kb_coffee_ru.txt` → Download raw file) с типом «База знаний» и спросите
   «Сколько стоит доставка?» — ответ с источником. «Есть ли парковка?» → `escalation_required`.
5. Агент **HR**: загрузите `resume_fictional_ru.docx` с типом «Резюме», отметьте его, спросите
   «Сделай сводку резюме». Только вымышленные резюме!
6. Swagger: `https://<имя>.onrender.com/docs` → **Authorize** → ключ → можно вызывать любой endpoint.

### Обновление и остановка

- Новый код: в Render → сервис → **Manual Deploy → Deploy latest commit** (`autoDeploy` выключен).
- Остановить и прекратить расходы: сервис → **Settings → Suspend** (или Delete). Ключ OpenAI можно
  отозвать в кабинете OpenAI.

### Частые проблемы

| Симптом | Причина / решение |
|---|---|
| `/health` → `"llm_configured": false` | не задан `OPENAI_API_KEY` или опечатка; Environment → исправить → Save (сервис перезапустится) |
| 401 в демо | ключ введён с ошибкой — сверьте с `DEMO_API_KEY` в Environment |
| Деплой падает при старте, в логах `API keys must start with 'aie_'` | `DEMO_API_KEY` не начинается с `aie_` или короче 24 символов |
| 502 `llm_auth_failed` | ключ OpenAI отозван/неверный |
| 502 `llm_quota_exceeded` | на аккаунте OpenAI нет средств/лимит исчерпан |
| 502 `llm_model_not_found` | модель недоступна для ключа — поменяйте `OPENAI_MODEL` |
| 429 `daily_limit_exceeded` | демо-лимит 10 запросов/день на пользователя (`DAILY_RUN_LIMIT_PER_USER`) |
| 429 `*spend_limit_exceeded` | достигнут дневной лимит расходов; увеличьте осознанно |
| «Пропали» файлы и история | бесплатный инстанс перезапустился; это ожидаемо без постоянного диска |

## Альтернативы (если Render не подходит)

- **GitHub Codespaces** — для разработчиков: открыть репозиторий в браузере → Code → Codespaces,
  затем выполнить команды из README в веб-терминале и открыть проброшенный порт 8000 (порт по
  умолчанию приватный — доступен только участникам с доступом). Это уже браузерная IDE, поэтому
  для «без VS Code» не рекомендуется.
- **Google Cloud Run / Railway / Fly.io** — тоже деплоят Docker-образ из GitHub, но требуют
  привязки платёжной карты; для постоянного стенда с PostgreSQL это следующий шаг.
